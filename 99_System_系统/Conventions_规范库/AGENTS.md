# AI 协作规则

- 编辑前先阅读 `HOME.md` 和目标目录的 `README.md`。
- 新内容按下一步用途放入 Inbox、Projects、Knowledge、Archive 或 System。
- 不确定时放 Inbox，不创建新的顶层目录。
- 内部笔记使用 `[[双链]]`，外部网页使用标准 Markdown 链接。
- 移动或改名后检查双链；不要批量猜测旧笔记含义。
- 不读取、提交或公开 `99_System_系统/Private_本地敏感` 中的内容。
- 未经用户明确要求，不删除笔记、不改写 Git 历史、不安装第三方插件。

> 本文件默认只作为规则模板保存。若所用 Agent 只会自动读取仓库根目录的 `AGENTS.md`，请按该工具的规则复制或链接到根目录；不需要自动加载时保持现状即可。
