# Obsidian AI 知识库模板

一个可直接打开使用的轻量知识库模板。它只依赖 Obsidian 原生功能，按内容的“下一步用途”分类，并提供一套适合新手的人机协作方法。

## 快速开始

1. 下载或克隆本仓库。
2. 在 Obsidian 中选择“打开本地仓库”，选中本目录。
3. 打开 [[99_System_系统/Conventions_规范库/人机协作快速入门|人机协作快速入门]]，复制第一段提示词，让 AI 先了解你的业务。
4. 确认 AI 给出的改造方案后，再让它调整目录、首页和常用模板。
5. 回到 [[HOME.canvas|知识库首页]]，在“当前焦点”卡片写下一件最重要的事，用它试跑。

> [!tip]
> 不必先设计完整分类。暂时不知道放哪里的内容先进入 `00_Inbox_收集箱`。

## 目录结构

| 目录 | 唯一职责 |
|---|---|
| `00_Inbox_收集箱` | 暂时无法判断用途的内容 |
| `01_Projects_项目` | 有目标、交付物或结束条件的事项 |
| `02_Knowledge_知识库` | 会继续查阅、学习或复用的主题知识 |
| `03_Archive_归档` | 已结束、只需保留上下文的内容 |
| `99_System_系统` | 附件、模板、规范和本地敏感目录 |

详细规则见 [[99_System_系统/Conventions_规范库/使用规范|使用规范]]；AI 协作见 [[99_System_系统/Conventions_规范库/人机协作快速入门|人机协作快速入门]]。

## 已配置

- 新建笔记默认进入收集箱。
- 附件库下设独立 `img` 文件夹，图片统一进入其中。
- 移动笔记时自动更新内部链接。
- 日记和模板使用 Obsidian 原生核心插件。
- 工作区布局、回收站、第三方插件、AI 会话和本地敏感内容不会进入 Git。

## 人机协作

先判断事情属于“对话、任务还是目标”：小事直接说，单次交付使用任务卡，长任务先用 `spec-builder` 或 `leader` 生成规格/任务书。完成一批任务或一个项目阶段后，建议用 `neat-freak` 整理文档与知识库。

- 快速教程：[[99_System_系统/Conventions_规范库/人机协作快速入门]]
- 单次任务模板：[[99_System_系统/Templates_模板库/T_AI任务卡]]
- Agent 规则模板：[[99_System_系统/Conventions_规范库/AGENTS|AGENTS.md]]

## 自定义

- 在 `02_Knowledge_知识库` 下建立自己的长期主题，不需要照搬别人的领域。
- 在 `99_System_系统/Templates_模板库` 修改或新增模板。
- 不需要日记时，在 Obsidian 的“核心插件”中关闭日记即可。
- 只有原生功能不够用时再安装第三方插件；本模板不捆绑插件代码。

## 公开前检查

- 不要把真实密码、Token、恢复码或身份信息写入仓库。
- `99_System_系统/Private_本地敏感` 只是被 Git 忽略，不是加密目录。
- 发布前检查 Git 暂存内容和历史；曾提交过的秘密仅从当前文件删除并不安全。
- 从私人知识库制作公开版本时，应使用全新的 Git 历史和全新的公开仓库。
